# Changelog

What changed in each release of `@tansy/theme-halo`. Releases up to 0.1.0 went out with every other package
on one version and are described in [tansy's changelog](../../CHANGELOG.md).

## 0.1.1 — 2026-11-22

- Sections past the editor's picks are filled, the Recommended panel stays filled with featured
  stories first, and wide covers are served at 1600 pixels, a thumbnail size `tansy` 0.1.1 adds.
- It now requires `tansy` ^0.1.1.
