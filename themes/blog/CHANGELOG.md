# Changelog

What changed in each release of `@tansy/theme-blog`. Releases up to 0.1.0 went out with every other package
on one version and are described in [tansy's changelog](../../CHANGELOG.md).

## 0.1.1 — 2026-11-22

Its post page now places the blog plugin's parts itself. From `@tansy/blog` 0.1.2 those parts
bring no outer margin or border of their own, so this release gives the space and the rule above
"More posts" and the comments in the theme's own CSS, and the post page looks as before. Use it with
`@tansy/blog` 0.1.2 or later.

Like every package, it now requires `tansy` ^0.1.1.
