title: Plugins
description: Every feature beyond the content core is a plugin on the same public extension API you would use yourself, plus one small adapter package per outside provider.
---

A plugin is a package you add to `plugins: []` in `tansy.config.ts`. It can add collections, field
types, blocks, permissions, dashboard pages, API routes, jobs, record hooks and components on the
site's pages. The plugins below are first-party, but they use nothing private: anything they do,
your own plugin can do. See [Extending Tansy](/docs/extending) for the API and
[Write and publish a plugin](/docs/guides/plugins) for the walkthrough.

```ts title="tansy.config.ts"
import { defineCms } from "tansy/config";
import { blog } from "@tansy/blog";
import { forms } from "@tansy/forms";

export default defineCms({
  plugins: [
    blog({ siteUrl: "https://example.com", comments: "moderated" }),
    forms({ notify: "owner@example.com" }),
  ],
});
```

Removing a line removes the feature. Plugins declare their own schema migrations, so adding one
and running `tansy migrate` is all a feature needs.

## Provider adapters

Several plugins keep the provider out of the core package: you add the feature plugin and one small
adapter for the service you use. Swapping services is swapping one package.

| Plugin | Adapters |
|---|---|
| [AI](/docs/plugins/ai) | `ai-openai`, `ai-anthropic`, `ai-google`, `ai-mistral`, `ai-groq`, `ai-deepseek`, `ai-xai`, `ai-openrouter`, `ai-gateway`, `ai-opencode`, `ai-commandcode`, `ai-openai-compatible` |
| [Email](/docs/plugins/email) | `email-resend`, `email-sendgrid`, `email-postmark`, `email-mailgun`, `email-brevo`, `email-ses` |
| [Payments](/docs/plugins/payments) | `payments-stripe`, `payments-polar`, `payments-creem`, `payments-dodo`, `payments-commet` |
| [CAPTCHA](/docs/plugins/captcha) | `captcha-turnstile`, `captcha-hcaptcha`, `captcha-recaptcha` |
| [Analytics](/docs/plugins/analytics) | `analytics-plausible`, `analytics-umami`, `analytics-google`, `analytics-fathom`, `analytics-matomo` |
| [File storage](/docs/guides/storage) | `storage-vercel-blob`, `storage-cloudinary`, `storage-uploadthing`, `storage-bunny` |
| [Search](/docs/guides/search) | `search-meilisearch`, `search-typesense`, `search-algolia` |

Every name above is scoped `@tansy/`.
